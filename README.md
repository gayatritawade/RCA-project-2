# Student Pass Prediction Using Logistic Regression

## Main file
Open `Student_Pass_Prediction_Logistic_Regression.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or upload it to Google Colab.

## Run
Install packages if required:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Then open the notebook and run cells from top to bottom.

## Dataset note
The included data is artificial and intended for learning only. It should not be used to assess real students.
